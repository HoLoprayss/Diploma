# Иконки приложения MealSafe

В этой папке содержатся SVG иконки для различных категорий продуктов и типов хранения.

## Основные иконки

- `fridge.svg` - Холодильник
- `pantry.svg` - Кладовая

## Категории продуктов

- `dairy.svg` - Молочные продукты
- `meat.svg` - Мясо и птица
- `vegetables.svg` - Овощи
- `fruits.svg` - Фрукты и ягоды
- `bread.svg` - Хлеб и выпечка
- `beverages.svg` - Напитки
- `snacks.svg` - Снеки и сладости
- `canned.svg` - Консервы
- `frozen.svg` - Замороженные продукты
- `grains.svg` - Крупы и злаки
- `fish.svg` - Рыба и морепродукты
- `eggs.svg` - Яйца
- `household.svg` - Бытовая химия
- `baby_food.svg` - Детское питание
- `nuts.svg` - Орехи и семечки

## Использование в коде

### Прямое использование SVG

```dart
import 'package:flutter_svg/flutter_svg.dart';
import '../constants/app_icons.dart';

// Отображение иконки холодильника
SvgPicture.asset(
  AppIcons.fridge,
  width: 24,
  height: 24,
)

// Автоматический выбор иконки по названию продукта
SvgPicture.asset(
  AppIcons.getIconByCategory('молоко'),
  width: 32,
  height: 32,
)
```

### Использование виджета AppIcon

```dart
import '../widgets/app_icon.dart';

// Простое отображение иконки
AppIcon(
  AppIcons.fridge,
  width: 24,
  height: 24,
)

// Иконка для продукта с автоматическим определением
AppIcon.product(
  'молоко',
  width: 32,
  height: 32,
  color: Colors.blue,
)

// Иконка для типа хранения
AppIcon.storage(
  'холодильник',
  width: 40,
  height: 40,
)
```

## Автоматическое определение категорий

Система автоматически определяет подходящую иконку на основе названия продукта:

- **Молочные**: молоко, кефир, сливки, творог, сметана, йогурт, сыр
- **Мясо**: мясо, говядина, свинина, курица, колбаса, сосиски
- **Овощи**: картофель, морковь, лук, капуста, огурцы, помидоры
- **Фрукты**: яблоко, груша, банан, апельсин, виноград, клубника
- **Хлеб**: хлеб, батон, булка, печенье, кекс, пирог
- **Напитки**: вода, сок, чай, кофе, квас, лимонад
- **Снеки**: шоколад, конфеты, чипсы, орешки, попкорн
- **Консервы**: консервы, тушенка, шпроты
- **Замороженные**: пельмени, вареники, блинчики, наггетсы
- **Крупы**: рис, гречка, овсянка, макароны, спагетти
- **Рыба**: рыба, лосось, семга, креветки, крабы
- **Яйца**: яйца, яйцо, перепелиные яйца
- **Бытовая химия**: моющее, порошок, мыло, шампунь
- **Детское питание**: детское, пюре, каша детская, смесь
- **Орехи**: орехи, грецкий, миндаль, фундук, семечки

## Технические характеристики

- Формат: SVG (векторная графика)
- Размер: 24x24 пикселя (базовый)
- Цветовая схема: Полноцветные иконки с возможностью перекраски
- Совместимость: Flutter с пакетом flutter_svg

## Добавление новых иконок

1. Создайте SVG файл в этой папке
2. Добавьте константу в `lib/constants/app_icons.dart`
3. При необходимости обновите логику в методе `getIconByCategory()`
4. Обновите этот README файл
